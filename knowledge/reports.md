# Compliance Reports & Dispatch

## Report Generation
CSV Auditor Pro produces executive-ready audit reports summarizing dataset health, issue counts, data distribution, and applied cleaning routines.

## Export Formats
1. **Cleaned CSV / TSV Download**: Download post-cleaned spreadsheet files ready for database ingestion.
2. **Formatted Excel (.XLSX)**: Multi-tab Excel workbooks containing cleaned data, audit summary dashboard, and issue breakdown.
3. **Executive PDF Audit Summary**: High-resolution branded PDF reports featuring charts, quality scores, and compliance sign-offs.
4. **Gmail Direct Email Dispatch**: Send formatted HTML compliance summaries and executive reports directly to stakeholders via integrated Google Workspace Gmail API or Compliance Gateway.
