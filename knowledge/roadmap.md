# Product Roadmap & Upcoming Capabilities

## Planned Features & Enhancements
1. **Automated Scheduled Audits**: Cron-based background CSV file monitoring via SFTP, Google Drive, and Cloud Storage buckets.
2. **PostgreSQL Direct Sync**: Real-time continuous replication of cleaned spreadsheet rows into target Cloud SQL / Postgres tables.
3. **Advanced AI Data Synthesizer**: Natural language synthetic CSV data generation for testing database migration routines.
4. **Custom Python / JavaScript Cleaning Scripts**: Ability to execute user-written sandboxed code blocks directly within the Cleaning Center.
