# Team Collaboration & Workspace Roles

## Workspace Permissions
Workspaces support multi-user collaboration with strict role-based access controls (RBAC):

- **Owner**: Master administrator with access to team management, billing settings, and API secret configuration.
- **Admin**: Full dataset management, cleaning execution, schema updates, and sending member invitations.
- **Editor**: Upload datasets, run cleaning center tools, create cell annotations, and export cleaned files.
- **Viewer**: Read-only permission to inspect datasets, view audit reports, and read cell comments.

## Audit Activity Logs
Every file upload, cleaning operation, schema edit, and email dispatch creates an immutable audit activity log entry visible in the **Audit History** tab.
